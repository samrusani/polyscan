# polyscan

Polymarket Scanner to find opportunities on Polymarket.

## Overview
Early-stage project exploring market discovery, signal detection, and alerting for Polymarket.

## Goals
- Identify mispriced or under-the-radar markets.
- Surface actionable signals with minimal noise.
- Make it easy to run locally and iterate.

## Roadmap (draft)
- Data ingestion and normalization
- Opportunity scoring and ranking
- Alerts and dashboards
